# NovaCraft — Android launcher project

این پروژه یک رابط کاربری اندرویدی قابل ساخت برای NovaCraft است. رابط فارسی و راست‌به‌چپ، انتخاب نسخه در رابط، صفحات مودها/فایل‌ها/حساب، تنظیم رم پیشنهادی، مودلودر، وضوح تصویر و پوسته دارد.

## مهم: این هنوز لانچر کامل Minecraft Java نیست

این پروژه به‌تنهایی Minecraft Java را اجرا نمی‌کند. فهرست نسخه‌ها فقط انتخاب رابط کاربری است؛ فایل‌های بازی دانلود نمی‌شوند. مدیریت مودها در این نسخه فقط فهرست محلی نام‌هاست و فایل مود نصب یا بررسی نمی‌کند. ورود Microsoft، Java runtime، رندرر/کنترل‌های لمسی، اجرای دنیاها، Forge، Fabric و NeoForge هنوز به یک موتور اجرایی واقعی متصل نشده‌اند. برای ساخت نسخهٔ کامل باید موتور سازگار اندرویدی جداگانه بررسی و یکپارچه شود؛ به‌دلیل محدودیت مجوزها، فایل‌های اختصاصی Minecraft در این پروژه بسته‌بندی نشده‌اند.

## راحت‌ترین روش ساخت APK (بدون نصب Android Studio روی کامپیوتر)

1. وارد https://github.com شوید و یک مخزن جدید به نام `NovaCraft` بسازید.
2. فایل‌های داخل این پوشه را در مخزن آپلود کنید؛ پوشهٔ `.github/workflows` هم باید آپلود شود.
3. در مخزن به تب **Actions** بروید و گردش‌کار **Build NovaCraft Android APK** را باز کنید.
4. روی **Run workflow** بزنید و اجرا را تأیید کنید.
5. بعد از سبز شدن اجرا، پایین صفحهٔ همان اجرا بخش **Artifacts** را باز کنید و `NovaCraft-Android-APK` را دانلود کنید.
6. ZIP دانلودشده را باز کنید؛ فایل `app-release.apk` داخل آن است. آن را به گوشی منتقل و نصب کنید.

گردش‌کار فایل‌های پلتفرم Android را در محیط ابری تولید می‌کند و سپس APK می‌سازد. این فرایند هنوز از راه دور اجرا نشده؛ بنابراین ساخت موفق تا زمان اجرای Actions تأییدشده نیست.

## ساخت محلی (اختیاری)

اگر Flutter و Android SDK نصب‌اند:

```bash
flutter create --platforms=android --org com.novacraft .
flutter pub get
flutter analyze
flutter build apk --release
```

APK خروجی در `build/app/outputs/flutter-apk/app-release.apk` قرار می‌گیرد.

## مجوز و استفاده

کد رابط کاربری این نمونه برای ویرایش و توسعه ارائه شده است. قبل از توزیع لانچر واقعی، مجوز تمام موتورهای اجرایی و کتابخانه‌های وابسته را بررسی کنید و فایل‌های بازی را فقط از مسیرهای مجاز دریافت کنید. رمز حساب را در این نمونه وارد نکنید؛ ورود رسمی هنوز پیاده‌سازی نشده است.
